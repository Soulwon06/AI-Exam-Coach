# AI-Exam-Coach — Product Principles

1. **One core action:** each screen has one obvious primary action.
2. **Simple by default:** hide internal AI scores and configuration.
3. **Knowledge-oriented:** Knowledge Domain → Study Unit.
4. **Evidence before guessing:** ground importance and explanations in course evidence.
5. **Separate signals:** Importance, Difficulty, and Mastery are distinct.
6. **AI recommends; student controls:** homepage recommendation plus manual Knowledge-page selection.
7. **Immediate feedback:** Question → Answer → Result → Explanation → Next.
8. **Skip ≠ Mastered.**
9. **Simulation is optional reinforcement.**
10. **Graceful degradation:** failure of one optional source must not block a course.
11. **Time-aware planning:** adapt to remaining exam time rather than assuming exactly seven days.
12. **No false completion:** unimplemented features must be explicit.
13. **Duolingo-inspired, not copied:** clear progression, cards, feedback, visible progress, low cognitive load; no XP/streaks/leaderboards/badges in MVP.
