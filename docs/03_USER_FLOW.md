# AI-Exam-Coach — User Flow

## First-time flow
Landing → Preference Selection → Create Course → Upload/Link Evidence → Course Preparation → Home.

## Home
Shows course name, days remaining, progress, important-content progress, evidence status, and current AI recommendation. Primary CTA: `开始学习`.

## Knowledge
Home → Knowledge → Knowledge Domain → Study Unit → Start Learning. Students may manually select any Study Unit.

## Learning modes
### Explanation First
Explanation → Question → Answer → Immediate Feedback → Next Question → Completion.

### Question First
Question → Answer → Explanation → More Practice → Completion.

## Practice
Exactly one question is displayed at a time. After answering: show result, correct answer, explanation, update mastery, then allow the next question.

## Review
Shows Study Units needing reinforcement, especially important weak units.

## Time pressure
The system may leave low-priority coverage incomplete to preserve Final Sprint time for important knowledge.
